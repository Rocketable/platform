# MCP Go SDK v1.7 Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade Rocketclaw's external MCP HTTP server to Go SDK v1.7.0 and serve stateless MCP protocol version `2026-07-28` without changing the public `session_prompt` contract.

**Architecture:** Update the shared Go module and regenerate its vendored dependency tree first. Then configure the existing `internal/rocketclaw/externalmcp` streamable HTTP handler as stateless with request-cancellation propagation; Rocketclaw continues to own conversation continuity through the required `external_conversation_id` tool argument rather than MCP transport sessions.

**Tech Stack:** Go 1.26.4, `github.com/modelcontextprotocol/go-sdk` v1.7.0, MCP Streamable HTTP, `net/http`, Testify, Go modules, vendoring, Jujutsu.

## Global Constraints

- Preserve the `/mcp` endpoint, Basic Authentication, `session_prompt` name, schemas, content, structured result, and `external_conversation_id` semantics.
- Preserve legacy-client support through SDK protocol negotiation.
- Enable protocol `2026-07-28` with `mcp.StreamableHTTPOptions.Stateless = true`.
- Set `mcp.StreamableHTTPOptions.PropagateRequestCancellation = true` because an aborted blocking HTTP request cannot receive its result.
- Do not add Rocketclaw configuration, compatibility modes, `MCPGODEBUG` flags, packages, exported APIs, logging, goroutines, timers, mutexes, or defensive guards.
- Do not introduce roots, sampling, MCP logging, subscriptions, standalone SSE, resumability, server-initiated calls, or multi-round-trip behavior.
- Keep the existing shared `mcp.Server`; the SDK owns ephemeral stateless sessions per request.
- Use the modern Go SDK defaults for error wrapping, HTTP error decoding, request-body limits, schema validation, and annotation serialization.
- Use `jj diff --git`; do not use Git or create a new Jujutsu change unless explicitly requested.
- Do not edit any `SOURCE_CLOC_BUDGET` or `GO_SOURCE_CLOC_BUDGET` value.
- README impact has been considered; no README update is needed because the public endpoint and application behavior do not change.

- [ ] **Step 2: Write the failing protocol integration test**

Add this test near the existing metadata-schema integration test in `internal/rocketclaw/externalmcp/server_test.go`:

```go
func TestStartSessionPromptServerUsesStatelessProtocol(t *testing.T) {
	server, err := StartSessionPromptServer(t.Context(), slog.New(slog.DiscardHandler), "127.0.0.1:0", nil, func(_ context.Context, _, externalConversationID, agent, input string, _ map[string]string, _ []SessionPromptAttachment, slackChannel string) (SessionResult, error) {
		assert.Equal(t, "external-1", externalConversationID)
		assert.Equal(t, "main", agent)
		assert.Equal(t, "hello", input)
		assert.Equal(t, "#ops", slackChannel)

		return SessionResult{ExternalConversationID: externalConversationID, Agent: agent, Answer: "reply"}, nil
	})
	require.NoError(t, err)
	t.Cleanup(func() { require.NoError(t, server.Close(context.Background())) })

	client := mcp.NewClient(&mcp.Implementation{Name: "test-client", Version: "1.0.0"}, nil)
	transport := &mcp.StreamableClientTransport{Endpoint: server.url, DisableStandaloneSSE: true}
	session, err := client.Connect(t.Context(), transport, nil)
	require.NoError(t, err)
	t.Cleanup(func() { require.NoError(t, session.Close()) })

	require.NotNil(t, session.InitializeResult())
	assert.Equal(t, "2026-07-28", session.InitializeResult().ProtocolVersion)
	assert.Empty(t, session.ID())

	tools, err := session.ListTools(t.Context(), nil)
	require.NoError(t, err)
	require.Len(t, tools.Tools, 1)
	assert.Equal(t, SessionPromptToolName, tools.Tools[0].Name)

	result, err := session.CallTool(t.Context(), &mcp.CallToolParams{Name: SessionPromptToolName, Arguments: map[string]any{
		"external_conversation_id": "external-1",
		"agent":                    "main",
		"input":                    "hello",
		"slack_channel":            "#ops",
	}})
	require.NoError(t, err)
	require.NotEmpty(t, result.Content)
	content, ok := result.Content[0].(*mcp.TextContent)
	require.True(t, ok)
	assert.Equal(t, "reply", content.Text)
}
```

This test uses `ClientSession.ID()` as the SDK-level assertion that no `Mcp-Session-Id` response header was accepted by the client. It lists and calls the tool to prove discovery and per-request metadata work across separate stateless POST requests.
